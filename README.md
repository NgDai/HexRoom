# HexRoom Project

Dự án HexRoom - Nền tảng quản lý & kết nối tìm phòng trọ và bạn cùng phòng (Monorepo).

## Cấu trúc dự án

```text
hexroom/
├── HexRoom-backend/      # Backend Java Spring Boot 3 & PostgreSQL
└── HexRoom-frontend/     # Frontend React / TypeScript / Vite & Ant Design
```

### 1. HexRoom-backend
- **Công nghệ:** Java 21, Spring Boot 3.3.4, Spring Data JPA, Spring Security (JWT), PostgreSQL, Swagger.
- Xem chi tiết hướng dẫn chạy backend tại [HexRoom-backend/README.md](./HexRoom-backend/README.md).

### 2. HexRoom-frontend
- **Công nghệ:** React 18, TypeScript, Vite, Ant Design, Tailwind CSS.
- Xem chi tiết hướng dẫn chạy frontend tại [HexRoom-frontend/README.md](./HexRoom-frontend/README.md).
